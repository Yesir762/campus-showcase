# 三维展示后台部署与使用

## 已实现的流程

进入 `/admin`，初始化独立管理员后使用账号密码登录。左侧选择场景，中间载入模型，右侧编辑场景、视角、热点和室内行走区。保存只更新草稿；预览仅管理员可见，发布更新公开页面，不需要重新构建。发布历史可以恢复完整场景快照。新场景默认隐藏；发布后需开启“前台可见”。

资源库支持高斯 PLY（含压缩 PLY）、SPLAT、KSPLAT、SPZ 和 SOG，以及图片。单文件上限默认 2 GiB，8 MiB 顺序分片；重新选择相同文件可续传。目录导入保留目录结构，检查 JSON 中引用的配套文件。目录选择根目录应包含 `lod-meta.json` 或 `meta.json`，不能包含无关文件。目录 JSON 单文件上限 256 KiB。

上传完成的单文件模型仍需转换节点检查。点击“转为 SOG”；已有 SOG 点击“校验 SOG”，不重新压缩。成功产物出现在资源库，点击“用于当前场景”创建独立模型版本，然后校准变换、视角和热点。源文件不会覆盖。转换失败会保留源文件与错误，可取消和重试。目录导入执行结构和依赖检查；发布前仍应预览确认渲染效果。

外部链接支持 HTTPS 和本站路径。外部模型直接由浏览器加载，不由服务端下载或转换，避免后台被用于访问内网。外部 CDN 需允许 CORS；正式发布前必须人工载入预览，确认依赖、跨域和手机资源可用。

热点使用当前观察目标初始化位置，可拖动三轴或输入坐标；高斯表面拾取与建筑遮挡检测尚不包含。图文采用纯文本安全渲染。室内编辑器显示俯视 X/Z 网格，绘制行走多边形和障碍；对应世界坐标必须与模型变换一致。配置视点高度后，入口和其他预设视角必须位于可行走区。边界不允许自交、退化或重复顶点。

## 本地启动

需要 Node 22.13 或更新版本。安装依赖后运行：

```sh
npm run db:local
npm run dev
```

在未提交的 `.dev.vars` 中配置随机的 `ADMIN_SETUP_TOKEN` 和 `CONVERTER_TOKEN`，每个至少 32 随机字节。不要复用测试口令。打开 `/admin`，输入初始化口令、账号和至少 12 字符的密码。初始化会幂等导入现有 JSON，不覆盖已经编辑的内容。数据库异常直接报错，不回退到静态内容。

本地 D1/R2 数据保存在 `.wrangler/state`，与生产环境隔离。新增 `public` 资源后运行 `npm run resources:index` 更新发布检查索引；正式构建前也会自动更新。

## 网站生产部署

继续使用现有 Sites 项目，`.openai/hosting.json` 已声明 `DB` 和 `BUCKET`。发布时托管平台创建绑定并应用 `drizzle` 中的迁移。不可修改已经应用的迁移；新增变更追加迁移。

通过 Sites 环境变量配置以下值，并在变更后重新部署：

| 变量 | 用途 |
| --- | --- |
| `ADMIN_SETUP_TOKEN` | 首次初始化和部署侧密码重置；按密钥保存 |
| `CONVERTER_TOKEN` | 转换节点认证；按密钥保存 |
| `MAX_SOURCE_BYTES` | 可选，默认 `2147483648` |
| `CONVERSION_TIMEOUT_MS` | 可选，默认 `3600000`；节点需使用相同值 |

首次部署可使用部署口令 POST `/api/admin/bootstrap` 导入原始公开展示数据，然后由拥有部署口令的人在 `/admin` 创建首个管理员。初始化入口在已有账号后关闭；没有公众注册。保管部署口令与数据库备份，勿将它们发给访客。

上传资源由 R2 提供：未发布资源只允许管理员访问；公开页面仅能访问其发布快照引用且校验通过的资源。源文件默认不公开。上传文件在独立 UUID 目录中，避免覆盖和缓存混用。

## 云端转换节点部署包

本次不创建收费云服务器。已提供 `converter/`，待准备服务器后部署。建议先用 4 vCPU、12 GB 内存进行现有模型实测；容器默认单任务并发、2 个编码线程，不能保证任意 2 GiB 源文件都能在此内存内完成。当前电脑没有 Docker，已使用同一 Node 程序在本地完成转换验证；Docker 镜像本身尚需在目标 Linux 主机构建验收。

服务器需安装 Docker 与 Compose，能通过 HTTPS 访问网站；不需要开放入站端口。步骤：

1. 将部署包解压，进入 `converter`。
2. 将 `env.example` 复制为 `.env`，填写真实站点地址和与网站相同的 `CONVERTER_TOKEN`，设置文件权限为仅管理员可读。
3. 执行 `docker compose up -d --build`。
4. 执行 `docker compose logs --tail=100 converter` 查看启动状态，后台资源库应显示节点在线。
5. 上传小型测试模型，确认从排队到“已完成”，再使用大模型实测并调整内存和磁盘。

转换工具固定为 `@playcanvas/splat-transform@3.8.0`；输入文件不作为命令或脚本执行。节点领取 90 秒任务租约，每 20 秒心跳。租约失效后任务可重新领取；完成提交幂等，旧节点不能提交新租约的结果。取消会在下一次心跳或 API 调用中终止处理。失败、取消和进程退出会清理临时目录；源文件仍保留在 R2。

容器临时目录默认 6 GB tmpfs，包含源文件、输出和转换中间数据，会计入内存消耗。大模型可将 `/tmp` 改为有容量配额的独立磁盘挂载，并按照实测调整限制。未接入节点时上传和编辑仍可用，转换任务保持排队；不要把“排队”当作转换成功。

## 备份、恢复与账号

后台导出包含场景、发布快照、资源索引和网站设置，不包含 R2 二进制资源、账号或会话。完整灾备需要同时备份 D1 与 R2；恢复时保留资产 UUID 和对象键。资源被草稿、发布历史或有效转换任务引用时禁止删除。

修改密码会撤销全部登录会话。忘记密码时使用部署侧脚本：通过环境提供 `SITE_URL`、`ADMIN_SETUP_TOKEN`、`ADMIN_USERNAME`，从标准输入传入新密码，运行 `node scripts/admin/reset-password.mjs`。不要把口令或密码放在命令参数和 shell 历史中。部署口令泄露后必须立即轮换并重新部署。

已完成类型检查、现有及新增测试，以及本地 API 的登录、草稿隔离、冲突、发布、上传续传与 PLY → SOG 验证。浏览器检查与实际转换样例覆盖记录见 `admin-verification.md`。没有真实 KSPLAT 等全部格式资料时，不把工具支持表等同于每种源数据均实测通过。

后续扩展：自动视角导览与解说、多级 LOD 生成、真实表面拾取、遮挡检测、常驻介绍牌、多语言、多人角色和审批、定时发布、访问统计，以及分块合并/裁剪/漂浮点清理。首版没有自动训练或自动发布转换产物。
