# 创意官网动效

使用 GSAP、ScrollTrigger 与 @gsap/react 管理开场、首屏和模块入场。保持原生滚动，首页开场通过 MotionReadyContext 延迟页面动画初始化，避免在覆盖层后提前播放。TechText 首帧传回实际字号，静态四字先执行遮罩进场，再切换同尺寸 Canvas。提前点击完成并停止 opening，继续原有像素退出。

首页 ABOUT / EXPLORE 与三个详情页英文标题已接入共享 SectionTitle；模块按标题、说明、卡片编排，图文增加遮罩、交错布局及桌面轻微视差。场景切换改为约 800ms tween，取消弹簧。GSAP 只操作卡片外层；图片视差和图片缩放分别作用于不同层。

三维窗口不做位移或缩放，通过 data-model-active 通知页面停止持续图片视差。退出三维后恢复。路由清理 useGSAP 上下文、媒体查询、观察器和事件；图片、字体及容器尺寸改变后刷新触发位置。后台完成入场时间线，键盘聚焦完成相关区域。减少动态效果呈现静态状态，手机关闭倾斜与持续视差。

验证：类型检查、构建、原有 13 项功能测试；浏览器实际开场/像素衔接、EXPLORE 终态、三个详情页、390px 博物馆布局、轻量模型载入、全屏进入退出。网页没有横向溢出。未完成稳定网络条件下首屏指标、同设备同视角升级前后帧率对比及真实手机 GPU 验收，不能据此声称性能无变化。系统减少动态效果与动效模块加载失败仍需专项浏览器测试。

## 2026-10-10：开场过渡闪烁修复

将页面动画拆为「准备」与「播放」两个状态。点击开场时，在像素遮罩完整覆盖期间准备首页的动画起始样式；遮罩退出后播放同一条时间线，不重新初始化。开场时间线在点击时暂停，不再强制跳到结尾，也不因退出状态变化而 revert；延迟到达的 TechText 字号回调不再改变退出中的字标。

GSAP matchMedia 增加始终匹配条件，确保普通桌面在未匹配手机或减少动态效果条件时也能运行编排。浏览器连续帧检查确认：遮罩期间首页保持起始值，退出后图片裁切和标题位移单向推进。鼠标进入、Enter 进入、同标签页刷新以及进入主校区详情通过检查；类型检查、13 项现有测试和生产构建通过。

## 2026-10-11：固定遮罩与首屏衔接

像素退出不再每帧生成 data URL。挂载一个内联 SVG mask，初始化矩形一次，只更新位置、尺寸和透明度，桌面 900ms、手机 700ms，保持 30 FPS 与 768 格预算。通过开场进入时跳过首页照片、导航和说明的隐藏式入场，保持它们可见；中文标题保留原有逐行位移与缩放入场，并在分解开始时立即播放，退出后继续同一条时间线，其他模块及详情页动效保留。

初始化失败在尚未应用遮罩时淡出；应用遮罩后出现异常直接退出。退出先隐藏开场再清理遮罩，避免恢复完整开场一帧。窗口或视觉视口尺寸变化直接退出，不重新生成网格。重复结束调用不会重新安排焦点定时器。

验证记录见 docs/pixel-dissolve-verification.md；纯函数测试覆盖每个像素尺寸、边界和透明度的单调性，不能替代浏览器合成验证。
