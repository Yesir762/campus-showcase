# 全屏按钮复核（2026-10-01）

## 最新修正：改为页面内全屏

用户再次报告原生全屏无法通过按钮退出，之前的自动化结论不足以覆盖实际使用。现已移除 requestFullscreen/exitFullscreen 和原生事件依赖，采用固定铺满浏览器内容区的页面内全屏。浏览器工具栏保持可见。

进入与退出由同一 React 状态切换；全屏时锁定页面滚动，退出后恢复原滚动状态与焦点，支持 Esc 和键盘焦点循环。所有模型共用控件，加载或报错时保留退出入口。

最新实测在每次切换后确认载入入口出现，再等待模型就绪，以全屏对话框实际出现和消失作为依据，不只检查按钮名称。自动分级、完整 LOD0/1/2、Block000 LOD0/1/2 均已确认按钮退出后恢复普通布局；自动与其他五档也已检查 Esc。全屏区域边界为 x=0、y=0、1280×720，覆盖本次浏览器内容视口。类型检查和构建通过。以下原生全屏测试作为历史记录，不代表该问题已在用户环境解决。

## 历史原生全屏检查
