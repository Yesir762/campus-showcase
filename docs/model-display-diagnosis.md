# 模型显示差异分析与解决安排

日期：2026-09-30。范围：用户提供的 259_raw.MP4、本地网站代码、余家头测试模型.zip。尚未获得线上异常页面链接，因此线上实际文件、错误日志和视觉异常仍待核验。

## 已确认的结论

视频长约 62.8 秒；检查 3、22、41、56 秒画面，建筑、树冠、操场总体完整，扫描外围可见少量散点和缺失。视频未显示正在渲染的具体 LOD，不能据此认定智图画面必定使用 LOD0。

本地 config/scene.json 固定加载 campus-lod2.ply；导入脚本硬编码读取两个分块的 LOD2，网站没有按距离切换到 LOD0/LOD1。

| 精度 | 两个分块总点数 | 原始 PLY 总大小，十进制 MB | 相对 LOD0 点数 |
| --- | ---: | ---: | ---: |
| LOD0 | 7,198,758 | 518.3 | 100% |
| LOD1 | 3,592,750 | 258.7 | 49.9% |
| LOD2 | 897,910 | 64.7 | 12.5% |

网站合并文件为 64,650,112 字节。它的两个分块数据体与压缩包原始 LOD2 逐字节一致，未额外删点或修改颜色、尺度、旋转和不透明度；只重写了点数并沿用首个分块头部。头部 min/max 注释仍是首个分块范围，应在后续导入改造中纠正，但本地 PlayCanvas 用点数据计算包围盒，不能将注释视为已确认的渲染故障。

等间隔抽样统计：LOD0 三轴尺度中位数约为 0.137/0.128/0.109，LOD2 约为 0.377/0.349/0.298，即后者约为前者 2.7 倍。少量较大的高斯覆盖相同区域，可以解释细节涂抹、窗户不清、树冠成团、轮廓粗糙。实际画质仍需要同视角渲染对照。

三档文件头均有位置、DC 颜色、opacity、scale、rot 属性，没有 f_rest 高阶球谐属性。因此当前合并没有删掉高阶球谐；升级到此压缩包的 LOD0 也不会新增这类属性。

LOD2 的 filter_3D 全为零；当前 PlayCanvas 不使用这个额外属性，未发现它在此文件中造成差异的证据。读取的尺度和 opacity 为有限数值，符合当前引擎指数/ sigmoid 解码方式；引擎会归一化四元数。

## 原因优先级

1. 若异常是细节模糊、涂抹、轮廓粗糙，固定 LOD2 是首要嫌疑。
2. 若异常是倒置、从底面看、模型错位或整体缺失，应优先检查坐标轴、旋转、相机和线上资源完整性；增加点数不能直接修复这些问题。本地实体配置旋转为 [90,0,0]、统一缩放 0.02，需要结合视频地标验证，不能仅凭该旋转认定错误。
3. 若异常是偏色或亮度差异，应对照色彩空间、曝光和渲染参数。
4. 若异常是加载失败或闪退，应核验 HTTP 状态、资源字节数、缓存、跨域及设备内存。本地文件存在不能证明线上分发成功。
5. 原扫描外围散点和缺失需要模型清理或补拍；单纯换渲染器或升精度不保证消除。

网页 maxPixelRatio 上限为 1.5，关闭 antialias；这可能影响屏幕锐度，但不能恢复 LOD2 中缺少的几何细节，也不能据此认定关闭抗锯齿就是高斯异常的原因。

## 解决安排和验收门槛

### 第一步：定位差异

取得线上链接和异常现象，核验线上加载的模型版本、文件完整性与控制台错误。固定视频中可识别建筑、操场和水塔，统一相机位置、朝向、FOV、画布尺寸与渲染参数；禁止把不同远近视角的画面当作精度对照。

### 第二步：三档精度对照

新建本地对照资源，不覆盖现用文件。先用同一个分块分别展示 LOD0/1/2，减少全量模型对设备性能的干扰；再验证两个分块的拼接。

对照目标：窗框、屋顶边缘、树冠、地面覆盖和分块交界。LOD0 若明显恢复细节，确认精度主因；同一异常若三档均出现，则检查渲染兼容性、坐标与相机，并在独立参考查看器中复现。

### 第三步：制作正式资源

依据对照结果选择精度，优先评估 LOD0 的 SOG 压缩；全场景若无法满足加载/内存/帧率要求，使用经过验证的 Streamed SOG 分块与分级加载。SOG 压缩与降低点数是不同操作，压缩前后需验收画质。

不要直接把约 518 MB 的全量原始 PLY 作为所有设备默认下载。转换时保留属性并核验变换。清理外围漂浮点，保留原始模型留档；独立校准移动端版本。

### 第四步：集成、验收与发布

新建场景版本，同步 scene.json 与 bindings.json，并保留旧版本用于回滚。校准朝向、取景、缩放和平移范围。

验收：固定视角画质对照；两分块无错位；旋转/缩放正常；Chrome 与 Safari 实机核验；记录加载时间、帧率和内存；持续浏览十分钟；检查模型 CDN/跨域/缓存与完整下载；不支持设备正确降级。达标后再切换线上默认版本。
